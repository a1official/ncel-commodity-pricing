Wheat Architecture

Step 1 to Step 9 Flow

A browser-safe visual flow for the Wheat S&D framework, from the first planning decisions through the final model integration layer.

01

Define Framework

Foundation

Lock the system design before data loading: geography, horizon, frequency, crop year, and HS code.

Scope

India + global context for Wheat.

Time Design

10 years historical, current season, and forecast horizon.

02

Build Supply Side

Supply DB

Create the Wheat supply layer with monthlyized acreage, yield, production, stocks, imports, and global production context.

Database

wheat_supply_factors.db

Main Tables

factor_definitions, factor_values, factor_monthly_values, factor_status, wheat_balance_sheet_*

Core Formula

Total Availability = Opening Stock + Production + Imports

03

Build Demand Side

Demand DB

Build the Wheat demand layer with food, exports, feed, seed, industrial use, stock build, and supporting demand context.

Database

wheat_demand_monthly.db

Main Tables

factor_definitions, factor_monthly_values, factor_status, source_inventory

Core Formula

Total Demand = Domestic Consumption + Exports + Feed + Seed + Industrial + Private Stock Build

04

Calculate Balance Sheet

Step 4

Combine supply and demand into year-level Wheat balance sheets and stocks-to-use reporting.

Inputs

Supply DB + Demand DB

Ending Stock

Opening Stock + Production + Imports - Total Use

STU

Stocks-to-Use = Ending Stock / Total Use × 100

05

Identify Price Drivers

Drivers DB

Track domestic, global, weather, and policy drivers that move Wheat prices and turn them into monthly driver signals.

Database

wheat_price_drivers.db

Main Tables

factor_monthly_values, driver_reference, driver_impact_score, driver_impact_score_annual

Examples

MSP, procurement, sowing, winter temperature, frost risk, Black Sea corridor, Russian policy.

06

Data Collection Plan

Source Layer

Load the daily and monthly source stack that feeds prices, arrivals, weather, benchmark pricing, stocks, trade, and support signals.

Sources

  • AGMARKNET spot prices
  • Open-Meteo weather
  • DFPD stocks and procurement
  • TradeStat imports and exports
  • World Bank global benchmark

Role

Feeds the support DB and the training matrix with a consistent Wheat feature layer.

07

Build Scenarios

Scenarios DB

Convert the base balance sheet and driver context into Bull, Base, and Bear trading ranges.

Database

wheat_scenarios.db

Main Tables

scenario_definitions, scenario_runs, scenario_assumptions, scenario_price_ranges

Logic

Bull / Base / Bear mapped to price ranges

08

Output Structure

Reporting DB

Prepare dashboard-ready balance tables, STU series, price correlation, risk flags, and scenario summaries.

Database

wheat_output_structure.db

Main Tables

balance_sheet_output, stocks_to_use_ratio_chart, price_correlation_series, risk_flags, scenario_summary

09

Model Integration

Integration DB

Formalize the active Wheat model, feature lineage, training runs, live forecast snapshot, and output contract.

Database

wheat_model_integration.db

Main Tables

model_registry, feature_source_map, training_runs, forecast_integration_status, api_output_contract

Logic

Daily Wheat ML model with embedded driver scores
